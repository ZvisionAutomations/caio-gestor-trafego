# Benchmarks Meta Ads — Saúde e Suplementos Brasil (2025–2026)

## CPL (Custo por Lead)

| Classificação | Faixa | Ação |
|---------------|-------|------|
| Excelente | < R$15 | Escalar |
| Bom | R$15–25 | Manter |
| Aceitável | R$25–35 | Monitorar — ajuste de bid -10% |
| Ruim | > R$35 | Pausa automática (se ≥ 50 cliques) |
| Crítico | > R$105 | Alerta imediato (3x threshold) |

## CTR (Click-Through Rate)

| Classificação | Faixa | Ação |
|---------------|-------|------|
| Excelente | > 3% | Escalar |
| Bom | 2–3% | Manter |
| Aceitável | 1,5–2% | Monitorar |
| Ruim | < 1,5% | Alerta |
| Crítico | < 1% após 1.000 impressões | Pausa |

## ROAS (Return on Ad Spend)

| Classificação | Faixa | Ação |
|---------------|-------|------|
| Excelente | > 4x | Escalar |
| Bom | 3–4x | Manter |
| Mínimo viável | 2x | Monitorar |
| Abaixo do mínimo | 1.8–2x | Ajuste de bid |
| Inviável | < 1.8x por 3 dias | Pausa + alerta |

## Frequência

| Classificação | Faixa | Ação |
|---------------|-------|------|
| Ideal | 1.5–2.5 | OK |
| Atenção | 2.5–3.0 | Monitorar |
| Alerta | 3.0–3.5 | Planejar rotação |
| Crítico | > 3.5 | Pausar anúncio + solicitar criativo |

## CPM (Custo por Mil Impressões)

| Público | Faixa Esperada |
|---------|---------------|
| Saúde feminina 45–60 | R$18–35 |
| Saúde masculina 40–65 | R$15–28 |
| CPM > 2x benchmark | Segmentação ruim ou competição alta |

## Segmentação Recomendada (Cold Traffic — sem pixel)

### New Woman (Saúde Feminina)
- **Interesses:** menopausa, climatério, saúde da mulher, hormônios naturais, bem-estar feminino, suplementos naturais, fitoterapia, qualidade de vida
- **Comportamentos:** compradores online, saúde preventiva, interessados em bem-estar
- **Faixa etária:** 45–65 anos
- **Gênero:** Feminino

### Alpha Pulse (Saúde Masculina)
- **Interesses:** saúde da próstata, vitalidade masculina, suplementos masculinos, fitness 40+, saúde preventiva masculina, longevidade, qualidade de vida masculina
- **Comportamentos:** compradores online, interessados em saúde, fitness lifestyle
- **Faixa etária:** 40–65 anos
- **Gênero:** Masculino

## Benchmarks de Conversão (WhatsApp como destino)

| Etapa | Taxa Esperada |
|-------|-------------|
| Clique no anúncio → abertura do WhatsApp | 60–80% |
| Abertura → resposta ao SDR | 15–30% |
| Resposta → qualificação positiva | 40–60% |
| Qualificação → venda | 20–35% |
| Funil completo (clique → venda) | 3–10% |

## Sazonalidade e Timing

- **Melhor horário para entregar:** 18h–22h (público 45–65 anos mais disponível)
- **Melhor dia:** Terça a Quinta (evitar segunda por baixo engajamento)
- **Período crítico:** Primeiros 3 dias de campanha — dados insuficientes para otimização agressiva
- **Recalibração:** 7 dias com ≥ 500 cliques para thresholds baseados em dados reais
